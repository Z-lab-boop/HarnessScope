Five-minute start

Build from source

HarnessScope currently requires Go 1.24 or newer. Clone the repository, build one local binary, then open the authenticated loopback dashboard.

Prefer the terminal? Run a scan without writing a report:

./bin/hscope scan . --no-report

● ● ● HarnessScope / source

git clone https://github.com/Z-lab-boop/HarnessScope.git
cd HarnessScope
go build -trimpath -o bin/hscope ./cmd/hscope
./bin/hscope serve . --port 0 --open

Operating boundary

Local and offline

01

The server binds only to 127.0.0.1 and uses a one-time authenticated launch URL. Scans, reports, snapshots, backups and rollback stay on the machine. There is no telemetry, hosted scanner or background monitor.

02

Preview before change

Fix is dry-run by default. Only explicitly selected SAFE plans can be applied; source hashes, local backups, rescan verification and automatic rollback bound the operation.

03

Redaction has limits

Credential-shaped values are redacted after parsing and paths are normalized for reports. No detector can recognize every proprietary secret, so review any report or diagnostic ZIP before sharing it.
