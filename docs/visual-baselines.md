The public `assets/dashboard-overview.png` is an illustrative local macOS Chromium capture of the committed synthetic `web/dashboard/tests/fixture-state.json`, rendered by `dashboard.spec.ts`. It is not a Linux regression baseline or evidence from real user configuration.

The implementing agent visually inspected the actual pixels at full size: all cards, tier labels, navigation, inspector and evidence footer are readable and unclipped. This records agent visual inspection, not an independent human review.

No reviewed Linux report, Overview or Graph baseline is currently checked in. The old `web/tests/__snapshots__/report.png` has unverified platform provenance and is not used as a regression baseline. Functional Playwright tests run on both CI platforms; the three explicitly named Linux visual tests are skipped until reviewed artifacts exist. This is an **OPEN release gate**, not a passing visual comparison.

To close the gate on a Linux host matching CI, install the locked Playwright Chromium and run both suites with `HARNESSSCOPE_REVIEWED_LINUX_BASELINE=1` and `--update-snapshots`. Inspect `web/tests/__snapshots__/report-linux.png`, `web/dashboard/tests/__snapshots__/dashboard-linux.png` (Overview) and `web/dashboard/tests/__snapshots__/graph-linux.png` (Graph). The dashboard images use reduced motion and the committed synthetic graph; check nodes, evidence edges and labels as well as Overview cards. Record Linux distribution, browser version, viewport, fixture commit, reviewer and all three image hashes here. Commit all inspected images, then run without `--update-snapshots`. Only Linux may compare these images. Never copy an illustrative macOS capture into a Linux baseline path.

Ordinary push/PR CI reports a visible OPEN warning and job summary while any required image is absent, without failing functional CI. Once all three files exist, it automatically runs strict comparisons. The reusable workflow accepts `strict_release` (default false); `release.yml` explicitly sets it true and waits for that workflow before building or publishing. Missing baselines therefore fail publication closed. Linux execution and review cannot be substituted by a cross-compiled binary or local macOS browser run.
